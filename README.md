## Overview

TDR Molotok is a precision mastering compressor offering VCA and optical emulation modes with program-dependent release, gentle ratio curves, and a musical response for bus and mastering work.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **TDR Molotok** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **VCA Mode** | Fast, punchy VCA compression for bus glue and transient control |
| **Opto Mode** | Gentle optical emulation for transparent, musical long-form dynamics |
| **M/S Processing** | Full mid/side mode for independent center and side compression |
| **Meter** | High-resolution gain reduction and output level metering |
